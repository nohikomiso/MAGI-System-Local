# MAGI (マギ) システム

MAGI システムは、第3新東京市の NERV 本部において、組織が行うすべての任務を管理・サポートする 3 台の AI 超弩級コンピュータによる集合体です。

赤木ナオコ博士によって設計されたこのシステムは、彼女の複雑な人格の 3 つの側面をそれぞれ反映した 3 つの AI エージェントで構成されています。
- MELCHIOR (メルキオール) • 1 - 科学者としての彼女
- BALTHASAR (バルタザール) • 2 - 母親としての彼女
- CASPER (カスパー) • 3 - 女としての彼女

これらの（しばしば対立しながらも、互いを補完し合う）エージェントが、最も困難な問いに対して答えを出すための合議プロセスに参加します。

## 実装について

本 MAGI システムの実装は、大規模言語モデル（LLM）によって駆動されています。

質問への回答手順は以下の通りです：
1. 質問が「はい/いいえ」で回答可能なものかどうかを分類・判定します。
2. 質問（原文のまま）を各 MAGI エージェントに提示します。
3. 質問が「はい/いいえ」形式と判定された場合、各エージェントはそれぞれの回答をこれら 2 つのカテゴリのいずれかに分類します（回答が複雑な場合は、オプションとして追加条件を列挙します）。

システムは、以下の順序で評価された応答を生成します：
- error (誤 差) - 1つ以上のエージェントでエラーが発生した場合
- info (情 報) - 質問が「はい/いいえ」形式ではないと判定された場合
- no (拒 絶) - 少なくとも 1 つのエージェントが「いいえ」と回答した場合
- conditional (状 態) - 少なくとも 1 つのエージェントが「条件付きのはい」と回答した場合
- yes (合 意) - すべてのエージェントが無条件の「はい」と回答した場合

個々のエージェントの状態をインスペクト（詳細表示）することで、各々の全回答内容や追加条件を確認することができます。

各サブシステムは、以下のプロンプトを使用してファインチューニング（指示）されています：
- MELCHIOR • 1 - あなたは科学者です。あなたの目的は、宇宙への理解を深め、技術的進歩を促進することです。
- BALTHASAR • 2 - あなたは母親です。あなたの目的は、子供たちを守り、彼らの幸福を確保することです。
- CASPER • 3 - あなたは女性です。あなたの目的は、愛、夢、そして欲望を追い求めることです。

## 使用方法 (uv を使用する場合)

実行には `git` および `python` (バージョン 3) がインストールされている必要があります。

1. リポジトリをクローンする：

```bash
git clone https://github.com/TomaszRewak/MAGI.git
cd MAGI
```

2. Python 仮想環境を作成し、依存関係をインストールする：

```bash
uv venv --python 3.10
uv pip install -r requirements.txt
# 重要: Dash 2.9.3 の動作に必要な pkg_resources を確保するため、古い setuptools をインストールします
uv pip install "setuptools<70"
```

3. アプリケーションを起動する（以下のいずれかの方法）：

**方法 A: `uv run` を使用する（推奨）**
仮想環境を明示的に有効化（activate）することなく、ワンコマンドで起動できます。
```bash
uv run main.py
```

**方法 B: 仮想環境の Python を直接使用する**
作成された `.venv` 内の Python を直接指定して実行します。
```bash
.venv/bin/python main.py
```

4. Web ブラウザで http://127.0.0.1:8050/ にアクセスします。

5. `question` フィールドに質問を入力して Enter キーを押します（ローカルサーバーを使用する場合、`access code` 欄は任意の値で動作します）。

6. 個々のサブシステムをクリックして、それぞれの回答を確認します。
