アクセスコード入力の撤廃と UI の簡略化・高品位化

【変更内容】
1. 完全ローカル化に伴う「アクセスコード」入力の削除
   - `main.py` のレイアウトから `ACCESS CODE` の入力フォームとラベルを削除。
   - `ai.py` の各関数（`is_yes_or_no_question`, `get_answer`, `classify_answer`）から、不要になった `key` 引数を削除し、内部ロジックを整理。

2. UI の高品位化と「質問」入力への特化
   - 入力エリアを `input-section` として独立させ、重厚なダブルラインの枠線とヘッダーを追加。
   - 質問入力のフォントサイズを `48px` に大幅アップ。
   - ラベルを `QUESTION:` に統合し、タイポグラフィを強調。
   - 入力フォームにエヴァンゲリオン劇中のターミナルを意識した発光・内光エフェクトを追加。

3. コードのクリーンアップ
   - 各コールバック関数の `State('key', 'value')` を削除。
   - 不要な `import` および古いコードコメントの整理。

【検証】
- `uv run main.py` で正常に起動し、質問入力のみが表示されることを確認。
- フォントサイズおよび枠線のデザインが、意図通り「プレミアムな質感」になっていることを確認。
